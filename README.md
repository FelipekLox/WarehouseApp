# Складской учёт логистического центра (WarehouseApp)

Консольное приложение на C#, демонстрирующее принцип **инкапсуляции** и работу по модели ветвления **Git-Flow**.

## Структура проекта
- `Product.cs` — класс товара с приватными полями, валидацией свойств, вычисляемыми свойствами (`TotalPrice`, `IsOutOfStock`, `IsBelowMinStock`), контролем минимального остатка, привязкой поставщика и списанием.
- `Supplier.cs` — класс поставщика с валидацией названия, телефона и ИНН (10 или 12 цифр).
- `Warehouse.cs` — класс склада с защитой внутреннего массива, возвратом копий массивов, поиском, удалением позиций и расчётом остатков.
- `Program.cs` — демонстрация всех сценариев и обработка исключений.

## Реализованные задачи
1. **Минимальный остаток и статус позиции** (`feature/product-minstock`)
2. **Поставщик как отдельный класс** (`feature/supplier`)
3. **Списание с указанием причины** (`feature/writeoff`)
4. **Удаление позиции и отчёт по дефициту** (`feature/warehouse-remove`)
